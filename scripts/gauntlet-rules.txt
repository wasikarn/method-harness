# gauntlet-rules.txt: which gauntlet level and tests a changed path needs (GH #749).
# Read by scripts/gauntlet-plan.sh. One rule per line:  <path pattern> <level> [test pattern...]
# Levels: low (lint only), medium (validate, audit, lint and the listed tests), full (everything).
# Patterns are bash `case` globs, where `*` also matches `/`: `hooks/gates/*` covers every file below.
# Every rule that matches a path counts: the path gets the highest of their levels and all their tests.
# SELF in a test list stands for the changed path itself (a changed test file runs itself).
# A path no rule matches gives full, and the plan takes the highest level over all changed paths.
# Tests come from the real layout: the files under tests/ that read or run the changed file.
